# FaceRoll-Group-4-Cowboys
Capstone 4905.401 Team Cowboys

Instructor Dashboard 

built using HTML, CSS, and JS


Within this dashboard, instructors will be able to do the following things:

* Login and access the instructor dashboard.
* View attendance records.
* Monitor attendance sessions in real time.
* Start a live attednace session for a selected course.
* See attendance marker for each student, such as Present, Late, and Absent.
* Manually override or correct a student's attendance record,
* Review student attendance history via the dashboard.
* View students who have opted out of facial recognition.
* Search attendance records by student name or ID.
* Filter attendance records by date range.
* Filter attendance records by attendance status.
* Export attendance records such as CSV files.
* View attendance reporting summaries and report tables
* Manage courses used for attendance sessions
* Configure attendance-related settings such as grace period and late attendance behavior.
